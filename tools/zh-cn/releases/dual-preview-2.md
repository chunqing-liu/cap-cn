发行标签：`v0.6.1-cn.2-dual-preview.2`。个人维护的 Windows x64 社区预览版，不是 Cap 官方发行，不替代 `v0.6.1-cn.2` 稳定版。

## 下载与升级

- [预览版 2 发行页](https://github.com/chunqing-liu/cap-cn/releases/tag/v0.6.1-cn.2-dual-preview.2)
- 下载 `Cap-CN-0.6.1-cn.2-dual-preview.2-windows-x64-portable.zip`，解压后运行 `Cap.exe`。
- 升级前保存工程、备份重要录像并完全退出旧版，包括系统托盘。不要同时用两个版本编辑同一个工程。
- 便携版默认使用程序旁的 `profile`。要沿用旧版录像库和设置，在两个版本均退出时，将旧版完整 `profile` **复制**到新目录；保留旧目录作为备份。自定义外部素材和录像目录需另行保留，跨电脑迁移仍需调整相关路径。
- 本次没有新的安装程序或后台自动更新。程序内部沿用 `0.6.1-cn.2`，请按发行标签和包名区分。
- 包含源码补丁、构建说明及第三方许可，不含个人配置、账号、录像、日志或测试素材；程序未签名，不要为启动它关闭安全防护。

## 相比预览版 1 的更新

### 每个缩放片段可以明确选择 A / B

选中缩放轨道上的片段，在右侧设置中选择“跟随鼠标 / 显示器 A / 显示器 B”。每段独立保存，自动和手动缩放均使用该选择。A / B 表示录制来源，不随画布左右位置交换。

固定选择 A 或 B 时，缩放只作用于该来源，另一屏不跟着放大。旧工程未设置目标时仍默认跟随鼠标；保留原来的手动焦点和进出动画。

### 最高 100 倍片段变速

右键视频片段，或点击片段设置按钮，打开“速度”：

- 保留原快捷倍速，增加 `10 / 16 / 25 / 50 / 100` 倍。
- “自定义倍速”支持 `0.25–100`，可输入 `75.5` 等小数并按 Enter。
- 只修改选中视频片段的倍率；后续片段和效果轨道沿用原有时间重排逻辑。
- 静音、保持音高和匹配速度选项保留。高倍速语音通常不可辨识，建议按需静音。

### 修复加速片段预览停住

预览解码追不上时，原逻辑可能反复取消未完成的取帧任务，造成播放位置继续走、画面长时间不更新。现在加速预览会保留正在解码的任务，并按倍速减少取帧请求；回到正常片段后恢复正常取样。

预览仍受解码吞吐量限制，可能短暂缓冲或慢于实时，不保证任意素材实时 100 倍或固定 60fps。正式导出不使用预览的稀疏取样逻辑，仍按所选倍率与导出帧率生成单个视频。100 倍会将 10 分钟压缩到 6 秒；有限帧率必然对原始时刻采样，但不会直接跳过整个片段。

## 已完成的验证

- Windows 原生编译检查和主程序构建通过；本包复用已验证的原生二进制，发布准备仅更新说明文件。
- 4 项直接使用生产源码的针对性测试通过，覆盖速度范围、非有限输入、时间重排、取样跨片段边界及不同帧率下的取样位置；不是全仓库测试。
- 原生界面输入 `75.5` 倍、点击 `100` 倍、保存重开并导出通过，后续正常速度片段及原始素材范围保持不变。
- 录屏工程的隔离副本上复现并验证了 8 倍速预览冻结的修复；100 倍合成素材预览持续更新，切回正常片段后恢复正常播放。
- `25 / 50 / 100` 倍双屏样例均输出单视频轨 `5120×1440 / 30fps`，时长和帧数符合预期，A / B 画面在抽查时间点持续变化。
- 100 倍“保持音高”样例导出音频非静音，测试音调保持约 `440Hz`。
- 同一正常速度单屏工程分别使用修复前后版本导出，五个抽查时间点的解码 RGB 像素一致。
- A / B 目标修正阶段已验证原生选择控件、逐段保存重开、单屏回归及 `5120×1440` 导出；本次未重新执行所有 A / B 组合。

## 仍存在的边界

- 继承[预览版 1 的限制](dual-preview.md#已知限制与未验证项)：双屏连续运动尚未达到稳定 60fps；不代表已达到 OBS 的采集性能。
- 本机 `5120×1440` H.264 导出会回退 CPU 编码，速度受硬件影响。
- 未完成跨电脑、全新系统、实际两小时录像完整播放 / 导出、高倍速音画同步压力及所有原功能的完整验收。
- 本次不承诺提升长录像加载速度、录制帧率或编码速度。重要录像应保留原始工程和独立备份。
