## 新增与扩展

### 两块显示器，同时录制为一个视频工程

在本地录制模式中勾选两台不同的显示器 A / B。录制后使用本地编辑器，两路画面共用剪辑时间轴，但可分别调整位置、大小、裁剪、显隐和层级。

支持左右并排、上下排列和画中画。两台 QHD 显示器默认并排为一个 `5120×1440` 画布，最终导出一个视频，不是两个独立成片。双屏模式暂不支持同时录制摄像头。

### 分割后的每个视频片段拥有独立自动缩放属性

选中视频轨道片段，可分别设置：

- 自动缩放开关。
- `1.00–4.50×` 倍率，支持直接输入小数。
- 鼠标跟随或点击后跟随。
- 点击后保持 `0.1–60` 秒，支持直接输入小数。

分割后两段先继承原片段属性，再修改任意一段不会修改另一段；保存、重开、调整顺序后仍保留。尚未独立设置属性的片段使用双屏面板中的默认值。无需逐帧打关键帧。

片段自动缩放保持双屏布局，只放大鼠标所在的显示器画面。双屏布局、画布和鼠标样式仍是全片设置，不是每个视频片段独立。

### 保留并修复原缩放轨道

修复此前本地双屏试用实现覆盖原缩放轨道的问题，恢复：

- 缩放轨道的自动 / 手动模式。
- 手动焦点调整面板。
- 轨道倍率、范围、弹簧进出动画及瞬时切换。

无论自动还是手动，缩放都**只作用于录像中鼠标所在的显示器**，不放大合成画布；另一块显示器的位置、大小和画面保持不变。手动焦点使用当前显示器内部的相对位置，鼠标切换显示器后，倍率和焦点也只作用于新显示器。

轨道生效时优先使用轨道效果，轨道之外使用视频片段自己的自动缩放；进出动画期间平滑交接，避免两套倍率相互覆盖或直接叠乘。关闭片段自动缩放不会关闭缩放轨道；轨道设为 `1×` 时不会被片段倍率覆盖。鼠标切换显示器时，原显示器立即恢复未缩放画面，避免两屏同时放大；没有可用鼠标位置数据时不会猜测目标屏幕。

### 可更换的独立鼠标层

使用本版新录制的双屏工程记录独立鼠标数据，可选择 Windows、macOS、macOS Tahoe、圆形或录制时的默认样式，并调整大小、平滑、点击效果或隐藏。

旧版双屏录像已经把原鼠标录入画面，不能无损替换或隐藏；本版会显示说明，不叠加第二个鼠标。此限制不影响分段倍率和缩放轨道编辑。

### 长录像时间轴导航

- **全片 / Ctrl+0**：显示整个视频，不再限制为十分钟。
- **定位播放头 / Ctrl+F**：将播放位置居中。
- **Ctrl+G**：聚焦时间输入框，可输入 `01:23:45.125`、`83:45.125` 或总秒数。
- **Ctrl 加 +/-、Ctrl+滚轮**：缩放时间轴；**Shift+滚轮**：横向移动。
- 底部总览条扩展到整条轨道宽度，支持点击、拖动定位；缩放滑块采用适合长录像的非线性刻度。

### 帧率选项

录制选项扩展至 `24 / 25 / 30 / 60 / 120fps`，MP4 导出支持 `15 / 30 / 60 / 120fps`。这是设置上限，不保证实际采集帧率，也不会补回原素材不存在的运动细节。

## 已完成的验证

- Windows 原生编译检查和主程序构建通过。
- 21 项双屏配置测试、直接使用生产源码的 44 项缩放 / 弹簧测试通过；1 项原有默认忽略的性能测试未启用。另有 3 项长时间轴计算测试通过。
- 原生编辑器实际分割视频并独立修改第二段的倍率、跟随模式、保持秒数和开关，第一段属性不变；保存重开及导出通过。
- 原生编辑器实际新增缩放轨道片段、输入 `2×`、切换手动模式、调整非中心焦点，预览正确变化；保存重开并导出后仍保留设置。
- 九组双屏测试工程均输出单视频轨 `5120×1440 / 30fps`，覆盖片段自动缩放开 / 关、手动焦点、进出动画、轨道自动跟随、无轨道自动缩放、轨道 `1×`、视频片段重排及 A→B→A 切屏。检查切屏前后和边界帧，非当前屏保持未缩放画面。
- 对比轨道外与仅使用片段自动缩放的成片，以及片段自动缩放开 / 关时的轨道效果，抽帧结果符合预期。
- 同一单屏测试工程分别在修复前后导出，五个时间点的解码 RGB 像素完全一致；这不是所有原功能的全量验收。
- A / B 鼠标位置、圆形 / Windows 样式及隐藏的成片对比通过；新录双屏短测包含两路视频及独立鼠标资源。
- 使用两小时合成录像检查全片视图、精确时间跳转、播放头居中和时间轴缩放；这不是实际两小时录屏的完整播放或导出测试。

## 已知限制与未验证项

- 本机 NVIDIA H.264 编码器不接受超过 `4096` 的画面宽度，`5120×1440` H.264 成片会使用 CPU 回退，速度受硬件影响。
- 双屏连续运动短测尚未达到稳定 `60fps`，不能视为已达到或替代 OBS 的高帧率采集性能。
- 不支持双屏加摄像头、不同显示器坐标工程的双屏合并，也不支持把普通 MP4 导入为具有可编辑鼠标轨的原生工程。
- 尚未完成其他电脑、全新系统、长时间新录鼠标层、暂停续录连续性、音画同步压力及所有原功能的完整验证。
- 本次不承诺提升长录像加载速度、采集帧率或编码速度。重要录像应保留原始工程和独立备份。
