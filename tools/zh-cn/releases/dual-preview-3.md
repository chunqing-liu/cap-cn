# 双屏编辑增强预览版 3

发行标签：`v0.6.1-cn.2-dual-preview.3`。个人维护的 Windows x64 社区预览版，不是官方发行，不替代 GitHub 上的稳定版 latest。

## 下载与升级

- [预览版 3 发行页](https://github.com/chunqing-liu/cap-cn/releases/tag/v0.6.1-cn.2-dual-preview.3)
- `Cap-CN-0.6.1-cn.2-dual-preview.3-windows-x64-setup.exe`：安装包，可覆盖安装到已有中文版目录，保留 `profile`，不覆盖官方版。
- `Cap-CN-0.6.1-cn.2-dual-preview.3-windows-x64-portable.zip`：免安装包，解压后运行 `Cap.exe`。
- 升级前保存工程、备份重要录像并完全退出旧程序，包括系统托盘。不要同时用两个版本编辑同一工程。
- 从便携版迁移时使用随包“维护与迁移”工具。不要直接删除旧目录中的 `profile`、自定义录像目录和外部素材。跨目录或跨电脑迁移需要调整相关内部路径。
- 主程序内部基础版本仍为 `0.6.1-cn.2`，发行标签、安装包版本及随包说明标记为 preview.3。没有后台自动更新。
- 程序未签名；不要关闭安全防护。不包含个人配置、账号、录像或测试素材。

## 本次修复

1. 选择 A/B 两个屏幕后，两块屏幕均显示录制确认按钮，并明确显示“开始双屏录制”“同时录制 A + B · 导出一个视频”。
2. 无论在 A 还是 B 上点开始，均使用同一组已选来源，不把 B 误作新的主屏而产生重复来源。
3. 取消录制确认后，再次打开选择器并点击完成，会重新启用已选屏幕，不需要先取消勾选再选一次。
4. 任一已选屏幕或确认窗口不可用时，提示错误，不静默降为单屏。

保留[此前的 100 倍速、加速预览修复和逐段 A/B 缩放目标](dual-preview-2.md)。本次不修改采集引擎、编码器、编辑器或导出算法。

## 分辨率说明

确认窗口中的 `2560×1440` 是当前单屏采集分辨率，不代表只录制一屏。两块同尺寸屏幕默认横向并排，画布为 `5120×1440`，导出仍为一个视频。最终分辨率以编辑器画布和导出设置为准。本次未增加总画布分辨率显示。

## 验证范围

- Windows 原生编译检查、主程序构建和 3 项来源选择针对性测试通过。
- 旧版原生界面复现：双屏仅一个确认窗口；取消后重开确认窗口数为零。
- 新版原生界面验证：双屏出现两个确认窗口，取消重开仍为两个；交换 A/B 顺序并从另一屏开始录制通过。
- 双屏短录制产生两个不同屏幕的有效视频来源，单屏录制仍只产生一个来源。
- 单屏取消重开后仍可开始和停止录制。
- 本次未重复此前全部 100 倍速导出、逐段缩放组合测试；这些实现未修改。

## 限制

本次是录制选择流程修复，不承诺提高采集帧率或达到 OBS 性能。尚未完成两小时双屏连续录制、跨电脑、热插拔和所有原功能的完整验收。其他限制沿用[预览版 2](dual-preview-2.md#仍存在的边界)。
