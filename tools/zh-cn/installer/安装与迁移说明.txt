Cap 中文试用版（非官方）

安装
适用于 Windows 10 2004 / Windows 11 的 x64 电脑，无需管理员权限。
安装包包含主程序、媒体依赖和微软 C++ 运行库，无需另外安装官方 Cap。
默认安装到当前用户的 AppData\Local\Programs\CapCN，也可选择其他可写目录。
请勿选择官方 Cap 的安装目录。安装程序不会覆盖官方版。
Windows N / KN 版本需要另行安装微软的媒体功能包。
程序未携带官方数字签名；请只使用你信任来源的本地构建。

升级
之后适配好的中文版安装包，直接安装到原目录即可。
设置和录屏位于安装目录的 profile 中，安装程序不会覆盖已有设置。
升级前请退出中文版，并建议先用“维护与迁移”备份。
卸载只移除已安装的程序文件，保留 profile 中的数据。

从当前免安装版迁移 / 换电脑
1. 退出要迁移的中文版。
2. 用“维护与迁移”导出备份；在原免安装版中也可运行 随包提供的迁移工具。
3. 新电脑安装中文版，在开始菜单打开“Cap 中文试用版 → 维护与迁移”，导入备份。
4. 已有数据会先保存为 profile-backup-日期时间，不直接删除或覆盖。
备份仅包含 profile 内的数据，不包含自定义外部录屏目录、外部素材和系统权限。
备份可能含有账号和私密录屏，请勿公开分享。
也可以在退出程序后，手动复制整个 profile 文件夹。

官方更新与汉化更新
“维护与迁移 → 检查官方更新”只读取官方发布信息，不下载或执行官方安装程序。
发现新版本后，仍需重新适配汉化、构建和验证，再用新的中文版安装包升级。
不能保证未来版本无需人工处理就能自动完成汉化；直接安装官方更新会丢失汉化。
维护用的源码补丁、词表和适配脚本随包提供，完整源码来源见 使用说明.txt。
当前没有配置远程中文版发布源，也没有后台定时检查或静默升级。

并行试用限制
配置与官方版隔离，不接管 cap:// 登录回调、不注册全局快捷键、不自动更新。
云端账号操作请继续使用官方版。录制、会员和导出权限实现没有被修改。
