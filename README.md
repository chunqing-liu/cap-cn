## 与官方版的区别

这个构建面向**本地录制、编辑和导出**，可与官方版并行安装：

- 设置、录屏和日志放在当前程序目录的 `profile`，不读取官方版账号。
- 默认录完打开本地编辑器，并启用点击自动缩放。
- 不接管 `cap://` 登录回调，不注册全局快捷键，不自动更新。
- 云端账号操作请继续使用官方版；此版本不是云端服务的汉化补丁。

## 备份、迁移与卸载

1. 退出需要备份或恢复的中文版。
2. 在开始菜单打开 **Cap 中文试用版 → 维护与迁移**，或运行程序目录中的 `维护与迁移.cmd`。
3. 选择“导出迁移备份”；换电脑安装后，再用同一工具导入。

导入前会把现有 `profile` 保存在独立的 `profile-backup-日期时间` 目录，不直接删除旧数据。迁移工具会调整当前和历史录屏目录中指向旧 `profile` 的内部路径。

备份只包含 `profile` 内的数据，**不包含自定义外部录屏目录、外部素材或操作系统授权**。备份可能含有私密数据，请勿公开分享。

安装版通过 Windows“已安装的应用”卸载，`profile` 会保留；免安装版删除目录前，请自己备份 `profile`。

## 官方更新后怎么办

“维护与迁移”中可以**手动检查官方稳定版本**，但不会下载或安装官方更新。

官方有新版本后，需要重新应用汉化、处理新增文案和冲突、构建并验证，再发布新的中文版。新的中文版安装包可覆盖安装到原目录，保留已有数据。

**目前没有后台更新服务，也没有承诺官方更新后自动同步。不要用官方安装程序覆盖此版本，否则会丢失汉化。**
